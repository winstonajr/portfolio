Personal developer portfolio showcasing projects, skills, and experience.

**Live:** [winstonajr.vercel.app](https://winstonajr.vercel.app)

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack) & React 19
- **Language:** TypeScript
- **Styling & Animation:** Tailwind CSS v4, Framer Motion, Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

### Build for Production

```bash
npm run build
npm run start
```
